# 2026-08-03 工作记录

## 项目：train（Spring Boot 3 / Java 17 多模块 Maven 项目）

### 1. 父 pom dependencyManagement 版本失效问题
- 现象：子 pom 中 fastjson2、hutool 不写 version 时爆红（version is missing）。
- 原因：父 pom 的 dependencyManagement 里对 fastjson2、hutool-all 错误使用了
  `<type>pom</type><scope>import</scope>`。`import` scope 只能用于真正的 BOM（如
  spring-cloud-dependencies）。普通 jar 依赖只需 `groupId + artifactId + version`，不要加 type/scope。
- 现状：父 pom 已改为正确写法（fastjson2/hutool/aop 仅声明 version），子 pom 可正常继承。

### 2. fastjson2 过滤器 API 易错点（重要，已踩坑）
- `JSONObject.toJSONString(Object, SimplePropertyPreFilter)` 在 2.0.62 **不存在**。
  JSONObject 只接受 `JSONWriter.Feature...`，不接受 Filter。
- 正确用法：用 `com.alibaba.fastjson2.JSON`（不是 JSONObject）：
  - `JSON.toJSONString(obj, SimplePropertyPreFilter)` ✅
  - `JSONObject.toJSONString(obj, JSONWriter.Feature...)` ❌ 只认 Feature
- 排除字段推荐写法：
  ```java
  SimplePropertyPreFilter excludeFilter = new SimplePropertyPreFilter();
  excludeFilter.getExcludes().add("mobile");
  JSON.toJSONString(obj, excludeFilter);
  ```
- `JSONWriter.Feature.ExcludePropertyPreFilter` 在 2.0.62 **不存在**（曾被误用），不要用。

### 3. LogAspect.java 改动
- 原 `PropertyPreFilters` + addFilter + addExcludes 写法改为 `SimplePropertyPreFilter` + `JSON.toJSONString`。
- import 改为 `com.alibaba.fastjson2.JSON` 和 `com.alibaba.fastjson2.filter.SimplePropertyPreFilter`。
- 已加 `@Aspect @Component`，切面现在生效（MDC.put("LOG_ID",...) 会被执行）。
- `restartedMain` 是 Spring Boot DevTools 热重启后的线程名，非流水号；LOG_ID 由 MDC 产生。

### 4. 环境注意
- PowerShell 下 `mvn` 不在 PATH，需用项目内 `.\mvnw` 编译（`.\mvnw -pl member compile`）。
- cmd 下 `mvn -o` 离线模式可能掩盖真实编译错误（假 BUILD SUCCESS），务必用 `.\mvnw` 真实编译验证。

### 5. LOG_ID 流水号不打印（修复）
- 现象：日志中 LOG_ID 为空/不显示。
- 根因：`LogAspect` 缺 `@Component @Aspect`，切面未生效，`doBefore()` 没执行，
  `MDC.put("LOG_ID", ...)` 从未调用，流水号未产生。
- 修复：给 `LogAspect` 加 `@Aspect @Component`，切面生效，MDC 写入后日志 pattern 的
  `%X{LOG_ID}` 正常显示。
- 附带修复：`logback-spring.xml` 原来定义了 **3 个 `<root>`**（logback 不允许，会叠加级别并重复收日志），
  改为 **1 个 root level=INFO 挂 STDOUT + TRACE_FILE + ERROR_FILE** 三个 appender。
- 注意：MDC 仅当前线程有效；若 Controller 方法异步（新线程），LOG_ID 会丢失需手动传递。
