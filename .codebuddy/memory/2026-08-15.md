## 乘车人 Passenger 编辑 bug 修复
- 现象：前端编辑乘车人时，每次保存都在数据库新增一条数据（id 变化），原记录未被更新。
- 根因：`PassengerQueryResp` 的 `id`/`memberId` 用 `@JsonSerialize(ToStringSerializer)` 序列化为字符串（防止 JS 53 位精度丢失雪花 id）。但 `PassengerSaveReq.id` 是 `Long`，Jackson 3.x 默认不会把字符串 `"208859..."` 转成 `Long`，反序列化为 `null` → 后端 `save` 走 `insert` 分支。
- 修复：
  - 后端 `member/.../req/PassengerSaveReq.java`：`id`、`memberId` 加 `@JsonDeserialize(using = NumberDeserializers.LongDeserializer.class)`，包为 `tools.jackson.databind.deser.jdk.NumberDeserializers`。
  - 前端 `web/src/views/Home/Passenger.vue`：表格加"操作"列 + 编辑按钮，新增 `edit(record)` 回填行数据到表单（先 `resetPassenger()` 再 `Object.assign(passenger, record)`）。

## 项目技术约定（重要）
- 项目使用 **Jackson 3.x**，包名为 `tools.jackson.*`（不是 `com.fasterxml.jackson.*`）。涉及 Jackson 注解/反序列化器时注意包路径。
- JWT 登录 token 有效期：24 小时（`JwtUtil` 中 `DateField.HOUR, 24`），common 与 gateway 两处一致。
- 雪花 id 跨前后端用字符串传递，避免 JS 精度丢失。
