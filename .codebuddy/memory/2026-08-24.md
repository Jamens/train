## FreeMarker 模板识别 / 渲染
- 用户反馈 `generate/src/main/java/.../ftl/test.ftl` 在 IDEA Ultimate 里"无法识别"（无语法高亮）。
- 排查：FreeMarker 依赖 2.3.34 已就位，属纯 IDE 识别问题；Ultimate 内置支持、无需插件。
- 修复动作：
  - 将 `test.ftl` 从 `src/main/java/com/junhao/generate/ftl/` 移到 `src/main/resources/ftl/test.ftl`（Maven 才会打包进 classpath，runtime 才能加载）。
  - 新增 `generate/src/main/java/com/junhao/generate/FreemarkerDemo.java`：独立 main，演示 `Configuration` + `setClassLoaderForTemplateLoading(..., "ftl")` + `getTemplate("test.ftl")` + `process`。实测传入 `domain=Member` 输出 `public class Member { private String name; }`，运行通过。
- 结论：模板放 resources 是运行时加载关键；IDE 不识别只影响编辑体验，用 `Override File Type → FreeMarker Template` 解决。
