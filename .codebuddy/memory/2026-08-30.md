## 日志约定
- 项目统一使用 **SLF4J**：`private static final Logger LOG = LoggerFactory.getLogger(Xxx.class);`（字段名 `LOG`，不是 `log`/`logger`），不用 `@Slf4j`、不用 `printStackTrace()`。
- 异常记录写法：`LOG.error("中文描述", e)` 或带占位符 `LOG.error("描述 {} ", var, e)`（异常对象放最后一个参数，SLF4J 会自动识别为 throwable）。

## SQL 安全（DbUtil）
- 表名属于 **SQL 标识符，无法用 PreparedStatement 占位**，必须先做白名单校验：`private static final Pattern TABLE_NAME_PATTERN = Pattern.compile("^[a-zA-Z0-9_]+$")` + `checkTableName()`。
- 普通值条件（如 `where table_name = ?`）用 `PreparedStatement.setString()`。
- 两个查询方法已改为 try-with-resources，消除 conn/stmt/rs 泄漏。
- **取列的元数据改用 `information_schema.columns` 参数化查询，替代 `show full columns from \`${tableName}\``**（后者表名是标识符必须拼接）：
  ```sql
  select column_name as `Field`, column_type as `Type`,
         column_comment as `Comment`, is_nullable as `Null`
  from information_schema.columns
  where table_schema = database() and table_name = ?
  order by ordinal_position
  ```
  列别名与 `show full columns` 完全一致（Field/Type/Comment/Null，Null 取 YES/NO），下游取值代码无需改动。
- 同理 `getTableComment` 也加上 `table_schema = database()`，避免同名表跨库取错注释。
- 依赖前提：JDBC url 必须带数据库名（`jdbc:mysql://host:3306/train?...`，配置里确实是），否则 `database()` 返回 NULL 会查不到结果。
- IDEA 的 "在 SQL 中使用的字符串可能不安全" 警告已彻底消除（不再需要 `//noinspection` 抑制）。

## generator-config-*.xml 的 XPath 取值方式
- 文件有 DTD：`<!DOCTYPE generatorConfiguration PUBLIC ... mybatis-generator-config_1_0.dtd>`，dom4j SAXReader 默认不联网校验 DTD，能正常解析。
- **区分属性 vs 子元素**：
  - `<jdbcConnection driverClass=... connectionURL=... userId=... password=...>` → 这些是**属性**，XPath 用 `//jdbcConnection/@connectionURL`、`//jdbcConnection/@userId`、`//jdbcConnection/@password`。
    - 误写成 `//property[@name='connectionURL']` 会得到 null（配置里的 `<property>` 只有 autoDelimitKeywords/beginningDelimiter/endingDelimiter/suppressAllComments）。
  - `<table tableName="passenger" domainObjectName="Passenger"/>` → `//table` 取元素，再用 `table.selectSingleNode("@tableName")` 取属性。
