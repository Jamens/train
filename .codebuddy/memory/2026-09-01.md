## 踩坑：Vue 模板里不能用 window
- 在 `<template>` 里写 `v-for="item in (window as any).XXX_ARRAY"` 会报
  `TS2339: Property 'window' does not exist on type '{...}'`（模板标识符走组件实例解析，不是全局作用域）。
- 修法：script 里定义顶层常量 `const XXX_ARRAY = (window as any).XXX_ARRAY as {...}[];`，模板里直接引用常量名。`<script setup>` 顶层常量自动暴露给模板。
- 这正是 Passenger.vue 用 `typeMap` 常量的原因。

## 踩坑：tsconfig.app.json 的 baseUrl 导致 vue-tsc 静默不检查【已修复 2026-09-01】
- `web/tsconfig.app.json` 里 `"baseUrl": "."` + `typescript ~6.0.2` → 报
  `TS5101: Option 'baseUrl' is deprecated ...`，**vue-tsc 直接 exit 2 退出，不做任何类型检查**（`pnpm build` 失败）。
- **已修复**：删掉 `baseUrl`，`paths` 改为 `"@/*": ["./src/*"]`（TS 4.4+ 的 paths 相对 tsconfig 自身解析，不需要 baseUrl）。

- 教训：**"vue-tsc 没报错"可能是假象**。若 TS5101 之类的致命配置错误存在，它会直接退出而不检查。判断检查是否真跑了，要注入故意的错误（如 `const __probe: number = "not-a-number";`）确认能被检出（TS2322 + TS6133）。

## 已知无害的 dev 警告：`Slot "default" invoked outside of the render function`
- 现象：`pnpm dev` 时控制台报 `<ATooltip title=null open=false placement="right">` + `at <AMenuItem>`。
- 根因：`ant-design-vue/es/menu/src/MenuItem.js` **无条件**用 Tooltip 包裹内容（第 197 行），非折叠态又把 `title` 置 null、`open` 置 false（第 185-190 行）——正好对应栈里的 `title=null open=false`。
- **不是用户代码问题**（Sider.vue 里没有 a-tooltip），也无法用户侧修复（没有开关，4.2.6 已是 4.x 最新版）。
- **仅 dev 环境**：Vue esm-bundler 里该 warn 被 `process.env.NODE_ENV !== "production"` 包裹。
  **已实测**：`dist/assets/*.js` 中用 .NET 直接读全文本，目标字符串 `invoked outside of the render function` 不存在，而对照组 `Vue`/`function` 存在 —— 确认已被 tree-shaking 移除。
- 结论：可忽略。生产控制台不会出现，不影响功能（菜单是静态内容，无响应式依赖需追踪）。

## 【已修】生成的前端页面运行时报 `Cannot read properties of undefined (reading 'reduce')`
- 根因：模板沿用了"后端枚举注入 window"的假设（`window.XXX_ARRAY`），但**本项目没有这套注入机制**（index.html 和 src 下都没有），所以该常量是 undefined，调 `.reduce()` 崩溃。
- 修法：**新增 `EnumUtil`，直接解析后端 Java 枚举类，把真实 code/desc 生成进前端常量**，不再依赖 window。
  - `Field` 新增 `enumName`（枚举类名）+ `enumList`（`[{key:"1",value:"成人"}]`）。
  - `EnumUtil.getEnumName(comment)`：正则 `枚举\[(\w+)]` 从字段注释提取枚举类名。
  - `EnumUtil.parseEnum(module, enumName)`：读 `${module}/src/main/java/com/junhao/${module}/enums/${enumName}.java`，
    用正则 `(\w+)\s*\(\s*"([^"]*)"\s*,\s*"([^"]*)"\s*\)` 解析出 code/desc。文件不存在时返回空列表（不崩）。
  - `ServerGenerate.fillEnumList(fieldList, module)` 在取完字段后调用。
- 代价：枚举变更后需重新生成前端文件（已在生成代码注释中说明）。

## FreeMarker 陷阱：行尾 FTL 注释会吃掉换行
- 写法 `// 注释文本 ${var}<#-- -->` 会导致下一行代码被拼接到注释里，例如生成
  `// ...枚举类 PassengerTypeEnumconst PASSENGER_TYPE_ARRAY = [` —— `const` 被注释掉，运行时报 not defined。
- 原因：行尾的 `<#-- -->` 会把其后的换行符一并剥离。
- 修法：别在行尾放 FTL 注释；注释写在独立行（整行只含 FTL 标签的行会被 FreeMarker 自动剥离，正是期望行为）。
