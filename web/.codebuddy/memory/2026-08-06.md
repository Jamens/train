# 2026-08-06 工作记录

## 项目概况（web 前端）
- 技术栈：Vue 3 + Vite + TypeScript + vue-router + Pinia + ant-design-vue（全局注册于 main.ts）+ @ant-design/icons-vue。
- 包管理：pnpm。开发环境为 Windows（PowerShell/cmd），脚本需跨平台。

## 已完成的修复/封装
- `src/utils/request.ts`：axios 封装。基于 `axios.create`（baseURL 默认 `http://localhost:8000`，支持 `VITE_API_BASE_URL` 覆盖，timeout 10s）；响应拦截器仅透传+错误统一 `notification.error`；`get/post` 辅助函数解包为 `Promise<Result<T>>`。注意：前端环境变量用 `import.meta.env.MODE`，不要用 `process.env`（浏览器无 process）。
- `src/api/index.ts`：业务接口层，`login(params)`、`sendCode(params)`，配套 `LoginParams`/`SendCodeParams` 类型。
- `src/views/Login.vue`：接入 `@/api`；`handleSendCode` 对手机号做非空 + `^1\d{10}$` 格式校验并 `notification.warning` 提示。
- `src/store/index.ts`：`useAuthStore`（组合式）管理登录态（user / isLoggedIn / login / logout）。
- `tsconfig.app.json`：补充 `baseUrl` + `paths { "@/*": ["src/*"] }`，使 TS 解析 `@` 别名。
- `vite.config.ts`：`__dirname` 改为 `import.meta.dirname`（兼容 native configLoader）。
- `package.json`：`dev`/`prod` 脚本改用 `cross-env NODE_ENV=xxx vite`（修复 Windows 下 `NODE_ENV` 不是命令的报错）；已安装 `cross-env@10.1.0`。

## 多环境配置约定（2026-08-06 补充）
- 环境文件：`.env.dev`（mode=dev）、`.env.prod`（mode=prod）。脚本用 `--mode dev/prod` 加载，而非 `NODE_ENV`。
- 环境变量必须用 `VITE_` 前缀才会暴露到 `import.meta.env`（VUE_APP_ 是旧 Vue CLI 约定，Vite 不暴露）。
- API 地址变量统一为 `VITE_API_BASE_URL`，由 `src/utils/request.ts` 读取作为 axios baseURL。
- `pnpm dev` => vite --mode dev；`pnpm prod` => vite --mode prod；`pnpm build` => vue-tsc -b && vite build --mode prod。
- 注意：base URL 现含 `/api/v1`，最终请求路径为 `<base>/member/member/login`，需后端确有该前缀。
